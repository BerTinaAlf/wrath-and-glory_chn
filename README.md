# Translation: 中文 [Wrath & Glory]

这是一个 Foundry VTT 汉化模组，为 `Warhammer 40,000: Wrath & Glory`
游戏系统提供中文翻译。

## 兼容性

- Foundry VTT：13-14
- Wrath & Glory 系统：7.5.3

## 安装

在 Foundry VTT 的「安装模组」中使用以下 Manifest URL：

```text
https://raw.githubusercontent.com/BerTinaAlf/wrath-and-glory_chn/main/module.json
```

安装后，在世界中启用本模组，并在 Foundry 的语言设置中选择 `中文`。

## 译名依据

规则术语以青甘甬宁战棋俱乐部翻译的《怒火与荣耀2E总规则》0.2 为依据。
PDF 内存在多种译法时，优先采用对应规则小节的标题或定义，统一用于界面和提示文本。
原有中英双语条目保留英文部分；PDF 未涉及的系统功能沿用现有译名。

具体译名、原译名和 PDF 页码见 [术语对照表](TERMINOLOGY.md)。

## 文件说明

- `module.json`：Foundry 模组声明文件
- `cn.json`：中文语言文件
- `TERMINOLOGY.md`：术语依据、译名对照与校对说明
